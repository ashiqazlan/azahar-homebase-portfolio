# Azahar HomeBase – Frontend

The Azahar HomeBase frontend is a React application built with Vite.

## Technology Stack

- React
- Vite
- JavaScript
- CSS

## Development

From the `frontend` directory:

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Production Build

Build the frontend:

```bash
npm run build
```

## Code Quality

Run ESLint:

```bash
npm run lint
```

The frontend communicates with the Azahar HomeBase backend API.
